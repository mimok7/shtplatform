# OnePay Invoice 자동입력 확장 기능

이 확장 기능은 Stay Halong 매니저에서 선택한 고객명, 이메일, 결제금액, 송장 참조번호, 설명과 만료일을 OnePay Invoice 신규 작성 화면에 자동 입력합니다. Chrome 비밀번호 관리자가 OnePay 로그인 필드를 채운 경우 로그인 제출과 `송장 생성` 화면 이동도 자동으로 진행합니다. 발급 후 표시되는 OnePay 공개 결제 링크를 매니저·매니저1의 `링크 복사` 버튼으로 전달하며, `OnePay 결제 확인`을 누르면 저장된 송장 참조번호로 거래 내역을 자동 조회합니다. 로그인 정보와 비밀번호는 복사하거나 저장하지 않으며, 인보이스 최종 제출·전송·결제 버튼도 누르지 않습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 폴더 `C:\SHT-DATA\sht-platform\tools\onepay-invoice-autofill`을 선택합니다.
5. 확장 프로그램 ID가 `kihedaabidghjlkcpbmkjalmppbfjidm`인지 확인합니다.

## 사용

1. 매니저 또는 매니저1의 결제 처리 화면에서 결제 항목을 선택합니다.
2. `OnePay 자동입력` 버튼을 누릅니다.
3. Chrome에 저장된 OnePay 계정이 로그인 화면에 채워지면 자동으로 로그인합니다.
4. 로그인 후 `송장 생성` 화면으로 자동 이동합니다.
5. 자동 입력된 고객명, 이메일, 참조번호, 설명, 금액, 만료일을 확인한 뒤 OnePay의 제출 또는 전송 버튼을 직접 누릅니다.
6. OnePay 화면에 결제 링크가 표시되면 매니저 또는 매니저1 화면으로 돌아가 `링크 복사`를 누릅니다.
7. 고객 결제 여부는 `OnePay 결제 확인`을 눌러 해당 송장 참조번호의 거래 상태를 조회합니다.

전달 데이터와 감지된 결제 링크는 Chrome 로컬 저장소에 최대 2시간만 보관되며 다음 자동입력 요청으로 교체됩니다.
